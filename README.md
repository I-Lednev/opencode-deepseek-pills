# OpenCode DeepSeek Pills

Плагин для OpenCode Desktop: четыре пилюли с балансом DeepSeek, расходом, тарифом и курсами.

## Возможности

- **Баланс и расход** — остаток DeepSeek, расход текущей сессии за всё время и за сегодня.
  - Переключатель валют **₽ / ¥ / $** прямо в меню первой пилюли; активная валюта показывается символом.
  - В рублях баланс и расход считаются по официальному курсу ЦБ на сегодня.
  - График расхода по дням за 14 дней: при наведении показываются дата и сумма; суммы в выбранной валюте.
  - Последние дни с расходом видны в строке под графиком.
- **Тариф DeepSeek** — дешёвое/дорогое время, обратный отсчёт до смены, окна дорогого тарифа.
- **Пополнение через plati.market** — курс поставщика, изменение, наценка к ЦБ, прогноз, график; клик по строке открывает лот.
- **Официальный курс ЦБ** — USD/RUB, изменение, прогноз, график.
- **Версия плагина** — первая строка в меню первой пилюли.
- **Проверка обновлений** — автоматически при старте и раз в 6 часов, плюс кнопка «Проверить обновление».
- **Автообновление** — скачивает zip, проверяет sha256, делает бэкап конфига, устанавливает и перезагружает OpenCode. Показывает окно прогресса с версией «откуда → куда» и краткой выжимкой изменений.

## Установка

1. Скачайте `opencode-transfer.zip` из [docs](docs/) или со страницы GitHub Pages.
2. Распакуйте.
3. В PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -SkipSessionImport
```

4. Подключите DeepSeek API key: **Settings → Integrations/Providers → DeepSeek → API key**.
5. Запустите OpenCode. Если пилюль не видно — `Ctrl+R`.

Установщик копирует плагин в `%USERPROFILE%\.config\opencode`, добавляет `"./deepseek-balance-plugin"` в `plugins` и настраивает команду `/balance`.

## Обновление

Плагин сам проверяет манифест:

```text
https://i-lednev.github.io/opencode-deepseek-pills/version.json
```

Если версия в манифесте выше установленной, в меню первой пилюли появится строка «Обновить до X». Она открывает ссылку на новый zip. Дальше — распаковать и запустить `install.ps1` или перетащить zip на `OpenCode-Pills-Updater.exe`.

Для ручного обновления также можно использовать `OpenCode-Pills-Updater.exe` (лежит отдельно): он делает бэкап конфига, выгружает старый плагин, запускает `install.ps1 -SkipSessionImport -ReplaceHistory` и перезагружает сервис.

## Публикация обновления

1. Поднимите версию в `src/gui-experimental.cjs` (`PLUGIN_VERSION`) и в `package.json`.
2. Запустите `.\release.ps1` — он соберёт `docs/opencode-transfer.zip` и обновит `docs/version.json`.
3. Запустите `.\publish.ps1 -Token "ghp_..."` — скрипт загрузит файлы в GitHub и включит Pages.
